TASK fin-b4-price-basis (FINANCIAL_CORE: KPIs only, no postings)

GOAL
Project KPIs must compare like with like. The audit (zakaria-farid/.agents/audits/SIM-2026-10-07-admin-lifecycle.md, B4) found these problems:
- The dashboard project comparison shows "بيع 1.0 م / تكلفة 1.8 م, -78%" for a 6,000,000 building with one unit sold. The sales bar uses only contracted value, against whole-building cost.
- The properties page shows "1 مليون" as the price of a 6,000,000 building.
- "قيمة المبيعات المتعاقد عليها" sums catalog unit prices (3,083,317) instead of contract values (3,083,334).
- The WIP total uses gross cost, which breaks the [user-confirmed 2026-10-07] "net of cost adjustments everywhere" rule.

DEFINITIONS (approved by the user)
- Project sales value = sum of gross_contract_value of live contracts (status <> 'Rescinded') on the project + catalog price (price_egp + tax_amount_egp) of every unit with no live contract. For a non-building or a building with no units: its contract value if contracted, else property price_egp.
- Contracted sales = sum of gross_contract_value of live contracts. Never catalog prices.
- Cost = net effective cost (calculateCostItemEffectiveTotals(item).netEffectiveCost from zakaria-farid/src/lib/erp/propertyCostEngine.ts), the same basis as calculatePropertyAuditMetrics.
- Margin = (sales value − cost) / sales value.
