<spec>
1. Private helper (module-level, not exported) `toScaled(value: number | string): { n: bigint; scale: bigint } | null`
   - exact decimal parse of the textual form; scale = 10^k where k = number of fractional digits kept (keep ALL digits).
   - numbers: use String(value) (NOT toFixed) so 1.005 parses as "1.005"; reject NaN/Infinity (return null).
   - strings: trim, strip commas, optional leading '-' or '+', digits with optional '.', optional exponent [eE][+-]?\d+
     (apply the exponent by shifting n / scale exactly). Anything else -> null.
2. Rounding helper `roundHalfUpDiv(num: bigint, den: bigint): bigint` — den > 0 after sign normalisation; result rounded
   half away from zero (matches existing times() sign handling: -0.005 -> -0.01).
3. Constructor / parseToCents:
   - number and string inputs go through toScaled, then cents = roundHalfUpDiv(n * 100, scale). null -> 0n (keep the
     current "garbage becomes 0" behaviour; empty string -> 0).
   - bigint and Decimal inputs unchanged.
4. times(factor):
   - Decimal factor: unchanged (cents * cents, /100 half-up).
   - number | string factor: scaled = toScaled(factor) (null -> treat as 0); result cents = roundHalfUpDiv(cents * n, scale).
5. div(divisor):
   - Decimal divisor: unchanged.
   - number | string divisor: result cents = roundHalfUpDiv(cents * scale, n) with sign handling; n == 0 -> throw the
     existing 'ERP Math Error: Division by zero'.
6. New public method `timesRatio(numerator: number | string | Decimal, denominator: number | string | Decimal): Decimal`
   - this × numerator / denominator with ONE rounding at the end. Decimal args use (cents, 100) as (n, scale).
   - denominator 0 -> throw 'ERP Math Error: Division by zero'.
   - JSDoc one line: "Apply a percentage or share without pre-rounding the ratio, e.g. amount.timesRatio(33.33, 100)."
7. Keep every other method and signature as is. Keep the file header comment accurate (update "Truncate/round" comment).
</spec>
