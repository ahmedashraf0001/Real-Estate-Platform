<A_feasibility_side_area>
Symptom: on the "دراسة جدوى" (feasibility) mode the shell still shows the side area with only its title bar
"أدوات الجدوى وهيكلة التكاليف" and no content, because the side widgets are rendered only when mode === 'built'.
The shell decides via context: `hasSideWidgets` (ERPWorkstationContext.tsx:634) honours an override set with
`setHasSideWidgets(val)`; the override resets automatically on tab change (line 628-631).
Fix in CostPricingCalculator.tsx:
  import { useERPWorkstationContext } from '../../../context/ERPWorkstationContext';
  (verify the relative path from src/components/admin/erp/v2/views/calculator/ to src/components/admin/erp/context/ — it is
   three levels up: '../../../context/ERPWorkstationContext'.)
  Inside the component, after the `property` const:
    const erpCtx = useERPWorkstationContext();
    const setHasSideWidgets = erpCtx?.setHasSideWidgets;
    const showSideWidgets = mode === 'built' && Boolean(property);
    useEffect(() => {
      setHasSideWidgets?.(showSideWidgets);
    }, [setHasSideWidgets, showSideWidgets]);
  Use useERPWorkstationContext (nullable), NOT useERPWorkstation (throws outside the provider).
  Change the existing side widgets condition `{mode === 'built' && property && (<ZFWorkstationSideWidgets>...` to
  `{showSideWidgets && property && (` — keep its contents unchanged.
</A_feasibility_side_area>
